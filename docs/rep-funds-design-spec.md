# Design Spec: 3.1.1 ข้อมูล Rep แต่ละกองทุน

- **Path:** `/service/dashboard-rcm/rep-funds`
- **กลุ่มผู้ใช้งาน:** ฝ่ายบริหาร, งานประกันสุขภาพ/งานลูกหนี้, ทีมเวชระเบียน และ Audit เรียกเก็บ สปสช.
- **Design Tokens:** อิงตาม `src/app/globals.css` (สีหลัก `var(--primary): #0D7446`, Sarabun, `tabular-nums`)

---

## 1. ปัญหาของหน้าเดิม และสิ่งที่แก้ไข
| # | ปัญหาเดิมที่พบ | สิ่งที่ได้รับการปรับปรุงในเวอร์ชันใหม่ |
|---|---|---|
| 1 | ข้อมูล REP สปสช. อยู่ในไฟล์ Excel กระจัดกระจาย เจ้าหน้าที่ต้องเปิดค้นหาทีละไฟล์ | รวมข้อมูล REP ทุกงวดและทุกกองทุนเข้าสู่ฐานข้อมูลเดียว ค้นหาและสรุปได้ทันที |
| 2 | เมื่อต้องการดูยอดเงินของคนไข้รายคน ต้องเปิด Excel หาคอลัมน์เอง | เพิ่มกล่อง **ตรวจสอบรายบุคคล (Patient Claim Lookup: HN + วันที่)** กรอกแล้วรู้เลข Rep, กองทุน, ยอดเงินชดเชยทันที |
| 3 | ไม่เห็นภาพรวมความคุ้มทุนแยกตามกองทุนหลักและกองทุนย่อย | จัดทำตาราง Matrix จำแนกตามกองทุนหลัก (UCS, OFC, SSS ฯลฯ) และกองทุนย่อย/โครงการ (Palliative, STEMI, CKD) พร้อมคำนวณอัตราชดเชย (%) |
| 4 | ติดตามเคสที่ถูกตัดเงินหรือติด Error ลำบาก | แสดงสถานะและรหัส Error Code พร้อมตัวเลขนับเคสรออุทธรณ์ (`appeal = 'Y'`) เพื่อเร่งส่งหลักฐานทวงหนี้ |

## 2. โครงสร้างหน้า (เรียงจากบนลงล่าง)
| ลำดับ | ส่วนประกอบ | รายละเอียดและพฤติกรรม |
|---|---|---|
| 1 | ส่วนหัว (Header) | หัวข้อ H1 `3.1.1 ข้อมูล Rep แต่ละกองทุน` + คำอธิบาย + ปุ่มล้างตัวกรอง + ปุ่มส่งออก CSV |
| 2 | ตรวจสอบรายบุคคล (Quick Patient Lookup) | ฟอร์มกรอก HN และวันที่รับบริการ + ปุ่มค้นหา + กล่องแสดงผลลัพธ์ดึงเลข Rep, สิทธิ, ยอดเงิน (ไม่มีชิปจำลอง เพื่อความสะอาดตาในการทำงานจริง) |
| 3 | แถบสรุปยอดรวม (Summary Metrics Bar) | 5 การ์ดสรุป: ค่ารักษาจริงรวม, ยอดเงินชดเชย สปสช., อัตราชดเชยเฉลี่ย, ผลต่างรายรับ, เคสรออุทธรณ์ |
| 4 | แถบเครื่องมือและตัวกรอง (Toolbar) | ตัวกรองปีงบประมาณ พ.ศ. + แผนก (OP/IP) + ตัวกรองกองทุนหลัก + ตัวกรองกองทุนย่อยสัมพันธ์กัน (Cascading SubFund) + ช่องค้นหา Live Search |
| 5 | ตารางสรุปรายกองทุน (Fund Matrix Table) | ตารางแจกแจงตามกองทุนหลัก, กองทุนย่อย, แผนก, จำนวนเคส, ค่ารักษาจริง, เงินชดเชย, อัตรา %, ส่วนต่าง, ปุ่มดูเคส |
| 6 | หน้าต่างเจาะลึกเคส (Detail Modal) | Modal ป็อปอัปแสดงรายชื่อผู้ป่วย (Masked HN ตาม PDPA) ในกลุ่มกองทุนที่เลือก พร้อมสถานะและ Error |

## 3. กติกาการแสดงผลและตรรกะทางธุรกิจ (Display & Logic Rules)
| หัวข้อ | กติกาที่กำหนด |
|---|---|
| **การแสดงวันที่** | ใช้ **ปี พ.ศ. ไทย** เสมอ เช่น "15 ต.ค. 2569", "ปีงบประมาณ 2569" |
| **การปกป้องข้อมูล (PDPA/PHI)** | Mask เลข HN แสดงเฉพาะหลักท้าย เช่น `xx-xxx45` และไม่แสดงเลขบัตรประชาชนแบบเต็ม |
| **ตัวเลขทางการเงิน** | จัดชิดขวา ใช้ `font-variant-numeric: tabular-nums` คั่นหลักพัน และทศนิยม 2 ตำแหน่ง |
| **ตรรกะผลต่างรายรับ** | `diff = compensated - income` (ถ้าชดเชยน้อยกว่าค่ารักษาจริง แสดงเป็นสีแดง Danger, ถ้าได้ครบแสดงสีเขียว Success) |
| **การจัดลำดับตาราง** | เรียงตามยอดเงินชดเชยที่ได้รับจริง (`totalCompensated`) จากมากไปน้อย |
| **การตอบสนองอุปกรณ์ (Responsive)** | ตารางมี `overflow-x: auto` เลื่อนได้อิสระบนมือถือ, ปุ่ม Action มีขนาดแตะสัมผัส `min-height: 44px` |

## 4. โทนสีและสถานะที่ใช้งาน (Semantic Colors)
| สถานะ / ข้อมูล | CSS Variable | ค่าสีพื้น / ตัวอักษร | วัตถุประสงค์การใช้ |
|---|---|---|---|
| สีแบรนด์หลัก | `var(--primary)` | `#0D7446` / ขาว | ปุ่มหลักค้นหา, แท็บเมนูที่เลือก, สีไฮไลต์เลข Rep |
| ชดเชยครบถ้วน (Paid 100%) | `var(--success-*)` | `#DCFCE7` / `#15803D` | ป้ายสถานะได้รับเงินชดเชยครบถ้วน, ตัวเลขผลต่างเป็นบวก |
| ติดอุทธรณ์ (Appeal Pending) | `var(--warning-*)` | `#FEF3C7` / `#B45309` | เคสที่จ่ายไม่ครบและอยู่ระหว่างยื่นอุทธรณ์ (`appeal = 'Y'`) |
| ปฏิเสธจ่าย / ขาดทุน (Denied) | `var(--danger-*)` | `#FEE2E2` / `#B91C1C` | เคสที่ถูกตัดจ่าย 0%, ตัวเลขส่วนต่างที่ขาดทุน |
| ป้ายแผนก / ทั่วไป | `var(--gray-*)` | `#F1F5F3` / `#334237` | ป้าย OPD / IPD และพื้นหลังหัวตาราง |
