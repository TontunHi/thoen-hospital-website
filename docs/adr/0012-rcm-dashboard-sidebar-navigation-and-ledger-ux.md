# 12. การปรับปรุงโครงสร้าง Navigation ของ Dashboard-RCM สู่ระบบ Collapsible Grouped Sidebar และการออกแบบ Dense Financial Ledger

Date: 2026-10-31

## สถานะ (Status)
ยอมรับแล้ว (Accepted)

## บริบท (Context)
เดิมระบบ Dashboard-RCM ใช้แถบนำทางแนวนอนด้านบน (`rcm-tab-nav` / `DashboardRcmNavTabs.tsx`) ซึ่งรองรับรายงาน 3–5 หัวข้อเดิม อย่างไรก็ตาม ในอนาคตระบบ RCM ของโรงพยาบาลเถินจะต้องรองรับรายงานทางการเงินและสิทธิการรักษาเพิ่มขึ้นอีกหลายมิติ (10+ รายงาน) การใช้แถบแนวนอนทำให้เกิดปัญหาหน้าจอแออัด ต้องเลื่อนจอแนวนอน และบดบังพื้นที่แนวตั้งของการดูตารางข้อมูล

นอกจากนี้ ในหน้ารายงานทันตกรรมประกันสังคม (`/service/dashboard-rcm/sss-dental`) การแสดงผลตาราง 19 คอลัมน์ (โหมดปีงบประมาณ) ยังขาดการจัดกลุ่มไตรมาส (Quarterly Grouping), ขาดระบบจัดเรียงข้อมูลตามความสำคัญ (Interactive Column Sorting), และมีสไตล์แบบ Inline ที่กระจายตัว ทำให้การใช้งานของฝ่ายการเงินและหัวหน้างานทันตกรรมยังไม่คล่องตัวเท่าที่ควร

## การตัดสินใจ (Decision)

1. **การปรับสถาปัตยกรรม Navigation เป็น Collapsible Grouped Sidebar:**
   - ปรับปรุง Shared Layout ที่ `src/app/service/dashboard-rcm/layout.tsx` ให้มีโครงสร้าง Two-Column Shell (Sidebar ซ้าย + Content ขวา)
   - สร้างคอมโพเนนต์ `DashboardRcmSidebar.tsx` รองรับการจัดหมวดหมู่รายงาน (Categorized Navigation Groups):
     - **หมวด 2.1 บริการผู้ป่วยนอกและทันตกรรม (OPD & Dental)**
     - **หมวด 2.2 บริการผู้ป่วยใน (IPD)**
     - **หมวด 5.2 การเงินและรายรับ (Finance & Billing)**
   - รองรับการย่อ/ขยาย (Collapsible) โดยบันทึกสถานะลงใน `localStorage` (`rcm_sidebar_collapsed`) เพื่อให้ผู้ใช้สามารถพับเก็บเป็นแถบไอคอน (Rail) เพื่อขยายพื้นที่แสดงตารางข้อมูลได้อย่างเต็มที่
   - รองรับ Mobile / Tablet Drawer (< 1024px) ด้วยปุ่ม Hamburger โดยอัตโนมัติ

2. **การออกแบบ Dense Financial Ledger สำหรับหน้ารายงานทันตกรรม (`sss-dental`):**
   - **Integrated Sticky Command Bar:** รวมตัวเลือกช่วงเวลา (ปีงบประมาณ/รายเดือน/กำหนดเอง), ช่องค้นหาแพทย์, และปุ่ม Export/Refresh ในแถบเดียว ประหยัดพื้นที่แนวตั้ง
   - **Compact KPI Metric Strip:** สรุปยอดรวม 5 ตัวชี้วัดสำคัญ (ครั้งรับบริการ, ค่ารักษาพยาบาลรวม, สิทธิเบิก UC, ชำระเอง/ใบเสร็จ, ลูกหนี้คงค้าง) ในแถบกระชับที่มีคอนทราสต์สูง
   - **Dense Responsive Table with Grouped Quarters:** จัดกลุ่ม 12 คอลัมน์เดือนเป็น 4 ไตรมาส (Q1: ต.ค.-ธ.ค., Q2: ม.ค.-มี.ค., Q3: เม.ย.-มิ.ย., Q4: ก.ค.-ก.ย.)
   - **Sticky Columns:** ตรึงคอลัมน์สำคัญ (#, ชื่อทันตแพทย์, ครั้งตรวจ, ค่ารักษารวม) ขณะเลื่อนตารางแนวนอน
   - **Interactive Column Sorting:** รองรับการคลิกหัวตารางเพื่อจัดเรียงลำดับแพทย์ตามยอดเงินหรือจำนวนครั้งตรวจ

3. **มาตรฐานการออกแบบ (Design Tokens & Tactile Standards):**
   - ใช้งาน Design Tokens ของโรงพยาบาลเถิน (`--primary: #0D7446`, `--bg-main`, `--bg-surface`, `--shadow-card`) ผ่านไฟล์ `layout.css` และ `page.css`
   - กำจัด Inline Styles ที่ไม่จำเป็นทั้งหมด เพื่อให้โค้ดสะอาด เป็นระเบียบ และบำรุงรักษาง่าย

## ผลกระทบ (Consequences)
- ระบบ Dashboard-RCM มีโครงสร้าง Navigation ที่ยืดหยุ่น สามารถเพิ่มหน้ารายงานใหม่ๆ ในอนาคตได้อย่างไม่จำกัด
- เจ้าหน้าที่การเงินและทันตแพทย์สามารถอ่านและวิเคราะห์ข้อมูลตัวเลขได้อย่างรวดเร็ว มีพื้นที่แสดงผลกว้างขวาง และสามารถดูภาพรวมรายไตรมาสได้ทันที
- ประสบการณ์ใช้งานสอดคล้องกับมาตรฐาน Hallmark และ Hospital Design Guidelines
