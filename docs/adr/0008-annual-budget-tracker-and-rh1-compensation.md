# 8. สถาปัตยกรรมระบบติดตามงบประมาณประจำปี และกำกับผลงานการชดเชยค่าบริการเขตสุขภาพที่ 1 (Annual Budget Tracker & RH1 Compensation)

Date: 2026-10-21

## สถานะ (Status)
ยอมรับแล้ว (Accepted)

## บริบท (Context)
โรงพยาบาลเถินต้องการสร้างหน้าศูนย์กลางสำหรับ **"ติดตามงบประมาณประจำปี"** ภายใต้เส้นทางบริการ `/service/budget-tracker` โดยมีข้อกำหนดหลักดังนี้:
1. **โครงสร้างรองรับหลายแหล่งงบประมาณ (Multi-Tab Sources):** ระบบจะต้องรองรับการดึงข้อมูลจากหลายแหล่งงบประมาณในรูปแบบแท็บหลัก (Top-Level Tabs) โดยจะทยอยพัฒนาทีละหัวข้อ
2. **หัวข้อแรก - ผลงานชดเชยค่าบริการรายกองทุน เขตสุขภาพที่ 1 (MIS HOS เขต 1):** นำระบบกำกับผลงานชดเชยค่าบริการทางการแพทย์ของ 103 หน่วยบริการใน 8 จังหวัดภาคเหนือ (ผลงานพัฒนาของ นพ.กุลพล ตั้งรัตนาพิบูล ผอ. รพ.สองแคว จ.น่าน) มาติดตั้งและปรับแต่งให้ตอบโจทย์ผู้บริหารโรงพยาบาลเถิน
3. **การโฟกัสโรงพยาบาลเถินเป็นค่าเริ่มต้น (Default Thoen Hospital Focus):** เมื่อเปิดหน้าจอขึ้นมา ต้องปักหมุดที่ "รพ.เถิน" (รหัส 11152, จ.ลำปาง, ขนาด M2, 81 เตียง, ประชากร UC 39,341 คน) และเปรียบเทียบในกลุ่ม `รพช.M2 B<=100` ทันที โดยยังเปิดให้เลือกดู รพ. อื่นได้
4. **การรองรับหลายปีงบประมาณ (Multi-Year Fiscal Support):** รองรับทั้งปีงบประมาณ 2569 และ 2570 และต้องมีสถาปัตยกรรมที่เปิดกว้างให้สามารถนำเข้าข้อมูลปีงบประมาณอื่นๆ (เช่น 2568 หรือปีในอนาคต 2571) มาแสดงผลได้อย่างง่ายดาย
5. **ความปลอดภัยของข้อมูล (Hospital Staff Protection):** เนื่องจากเป็นข้อมูลสถานะทางการเงินและงบประมาณ จึงต้องจำกัดสิทธิ์ให้เฉพาะบุคลากรโรงพยาบาลที่เข้าสู่ระบบแล้วเท่านั้น (`verifyMemberSession()`)

## การตัดสินใจ (Decision)

### 1. สถาปัตยกรรมเส้นทางและเลย์เอาต์ 2 ชั้น (Two-Tier Layout)
- **URL หลัก:** `/service/budget-tracker`
- **แท็บระดับบนสุด (Main Source Tabs):**
  - `Tab 1: ผลงานชดเชย เขต 1 (MIS เขต 1)` *(พัฒนาในเฟสนี้)*
  - `Tab 2+: แหล่งงบประมาณอื่นในอนาคต` *(เว้นโครงสร้างรองรับการขยายตัว)*
- **แถบควบคุมภายใน Tab 1 (Sub-Views & Controls):**
  - **ตัวเลือกปีงบประมาณ:** สลับปี 2570 (ล่าสุด) หรือ 2569
  - **มุมมองหลัก (Views):**
    - `บทสรุปผู้บริหาร รพ.เถิน (Executive Summary)`: วิเคราะห์จุดเด่นที่ทำได้ดี (Good), จุดที่มีโอกาสพัฒนาเพิ่มรายได้ (Opportunity พร้อมยอดเงินประเมินเป้าหมาย), และรายการที่ยังไม่ได้เริ่มเบิก (Zero)
    - `ภาพรวมการโอนเงิน (L1)`: กองทุนหลัก (OP, IP, แพทย์แผนไทย, งบลงทุน, ฟื้นฟู, ไต, เอดส์, NCDs)
    - `ข้อมูลรายกองทุนย่อย (L2)`: กองทุนย่อย 250+ รายการ
    - `เมทริกซ์เทียบเพื่อน (Matrix Heatmap)`: กองทุนย่อย × โรงพยาบาลในกลุ่ม
  - **ตัวกรองกลุ่มเปรียบเทียบ:** จังหวัด, ขนาด A-F3, กลุ่มระดับบริการ, และระบบโฟกัส/ปักหมุด รพ.

### 2. สถาปัตยกรรมข้อมูลแบบ Data Module & Service Layer (Plug-and-Play)
- นำชุดข้อมูล JSON จากต้นฉบับมาแปลงเป็นโครงสร้าง Data Module ที่มี Type Safety ใน `@/data/budget/rh1-2569.json` และ `@/data/budget/rh1-2570.json`
- สร้าง Domain Service `@/lib/budget/rh1BudgetService.ts` เพื่อทำหน้าที่:
  - ลงทะเบียนชุดข้อมูลปีงบประมาณ (Fiscal Year Registry)
  - ประมวลผลและคำนวณสถิติ (ยอดรวม, ยอดต่อหัว UC, อันดับ, มัธยฐานกลุ่ม)
  - คำนวณ Executive Insights อัตโนมัติสำหรับโรงพยาบาลเถิน

### 3. มาตรการความปลอดภัย (Defensive Auth)
- หน้า Server Component `/service/budget-tracker/page.tsx` ตรวจสอบเซสชันด้วย `verifyMemberSession()` ฝั่งเซิร์ฟเวอร์ หากไม่มีเซสชันจะถูก Redirect ไปยัง `/member/login` ทันที

## ผลสืบเนื่อง (Consequences)
- **ประสิทธิภาพสูง (Instant Response):** การประมวลผลบนหน่วยความจำผ่าน Service Layer ทำให้การสลับปีงบประมาณ สลับมุมมอง หรือเปลี่ยนตัวกรองกลุ่มเปรียบเทียบทำงานได้ทันทีโดยไม่ต้องยิงคิวรีซ้ำ
- **ความยืดหยุ่น (Extensibility):** เมื่อได้รับไฟล์ข้อมูลปีงบประมาณอื่นๆ เพิ่มเติม เพียงแค่นำไฟล์มาลงทะเบียนใน Service Registry หน้าจอจะแสดงตัวเลือกปีใหม่ให้อัตโนมัติ
- **ตรงตามเป้าหมายผู้บริหาร:** ผู้บริหารโรงพยาบาลเถินสามารถเห็นสถานะทางการเงิน จุดเด่น และโอกาสเพิ่มรายได้ในกลุ่ม รพช. M2 ได้ทันทีที่เข้าใช้งาน
