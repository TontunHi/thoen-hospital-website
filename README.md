# 🏥 Web Application - โรงพยาบาลเถิน (Thoen Hospital)

ระบบเว็บไซต์หลักและแพลตฟอร์มบริการดิจิทัลสำหรับประชาชนและบุคลากร **โรงพยาบาลเถิน อำเภอเถิน จังหวัดลำปาง** พัฒนาด้วยเทคโนโลยีเว็บสมัยใหม่ มุ่งเน้นความคล่องตัวในการเข้าถึงข้อมูล ประสิทธิภาพความเร็ว และความปลอดภัยทางข้อมูลระดับสูง (Modern, Elegant, Secure & Premium Experience)

---

## 🛠️ เทคโนโลยีหลักที่เลือกใช้ (Tech Stack)

* **Core & Architecture:** [Next.js 16 (App Router)](https://nextjs.org/) + TypeScript 5
* **Design & Styling:** Vanilla CSS (เขียนควบคุมสไตล์ทั้งหมดด้วย CSS ตัวเองผ่าน Design Tokens เฉพาะ ไม่ผ่าน CSS Framework เพื่อความกะทัดรัดและประมวลผลได้เร็วที่สุด)
* **Icons Library:** [Lucide React](https://lucide.dev/)
* **Database ORM:** [Prisma Client](https://www.prisma.io/) (จัดการฐานข้อมูลเชิงสัมพันธ์ได้อย่างราบรื่น)
* **Database Systems:**
  * **Primary Database (MySQL/MariaDB):** รองรับระบบจัดการเนื้อหา (CMS) และระบบสารสนเทศสมาชิกบุคลากร
  * **Secondary Databases:** เชื่อมโยงฐานข้อมูลการเงิน (Salary) และฐานข้อมูลห้องฉุกเฉิน (HOSxP/HIS) ในเครือข่ายภายในโรงพยาบาล
* **Validation & Security:** [Zod](https://zod.dev/) (Rigid Payload Validation) + HMAC-SHA256 Session Signature (ป้องกันการลักลอบแก้ข้อมูลคุกกี้)

## ✨ คุณลักษณะเด่นและระบบการทำงาน (Key Features)

### 📢 สำหรับประชาชนทั่วไป
1. **ศูนย์ข่าวสารและประชาสัมพันธ์:** หน้าหลักแสดงภาพสไลด์กิจกรรมที่ปรับเปลี่ยนได้ และกระดานข่าวสารประชาสัมพันธ์ ความรู้สุขภาพ ประกาศรับสมัครงาน พร้อมระบบนับยอดเข้าชมป้องกันการปั๊มสแปม
2. **ระบบตรวจสอบวันนัดหมายแพทย์ (/check-date):** ประชาชนทั่วไปสามารถตรวจสอบตารางนัดหมายล่วงหน้าของตนเองได้ด้วยเลขบัตรประชาชน 13 หลัก
   * *ความปลอดภัยด้านข้อมูล:* ปิดบังตัวเลขบางส่วนของชื่อและนามสกุลเพื่อปกป้องสิทธิ์คนไข้ พร้อมติดตั้งตัวจำกัดคำขอสแปม (Rate Limiter)

### 💼 ระบบบริการบุคลากรภายใน (Member Portal)
1. **ระบบลงทะเบียนและล็อกอินแบบไร้รหัสผ่าน (OTP-Based Login):** เข้าใช้งานระบบผ่านเลขบัตรประจำตัวประชาชน โดยระบบจะสร้างรหัสผ่านใช้ครั้งเดียว (OTP 6 หลัก) ส่งยืนยันไปยังอีเมลส่วนตัวของเจ้าหน้าที่
2. **ระบบพิมพ์ใบสั่งงานและขอสั่งผลิตสื่อ (PR Orders Management):** เจ้าหน้าที่สามารถกรอกแบบฟอร์มขอสั่งผลิตสื่อประชาสัมพันธ์ เลือกรูปแบบงาน ขนาด และช่องทางเผยแพร่
3. **ระบบลงนามและอนุมัติใบงาน (Approval Workflow):** ใบคำขอผลิตสื่อจะถูกส่งเข้ากล่องงานรออนุมัติตามลำดับขั้น โดยหัวหน้ากลุ่มงาน/ผู้อำนวยการสามารถลงลายเซ็นดิจิทัล (Digital Signature) เพื่ออนุมัติและสั่งพิมพ์เป็นเอกสารใบสั่งงาน A4 ได้ทันที
4. **ระบบสลิปเงินเดือนออนไลน์ (SSO Salary Slip):** เชื่อมต่อบัญชีระบบสมาชิกทั่วไปเข้ากับระบบตรวจสอบรายรับ-รายจ่าย (Salary) ภายนอกของโรงพยาบาลอัตโนมัติ ทำให้ล็อกอินดูสลิปเงินเดือนและโอที (OT) ย้อนหลังได้โดยไม่ต้องกรอกรหัสผ่านซ้ำซ้อน
5. **ระบบสถานะผู้ป่วยห้องฉุกเฉินเรียลไทม์ (ER Live Status):** แสดงยอดผู้ป่วยฉุกเฉินปัจจุบัน ระดับสีความรุนแรง (Triage) และสถิติภาพรวมประจำเดือน
   * *TV Mode:* หน้าจอปรับแต่งพิเศษสำหรับแสดงผลเปิดทิ้งไว้บนจอทีวีขนาดใหญ่ภายในแผนก (ซ่อน Navbar และมีระบบดึงข้อมูลอัปเดตสถานะอัตโนมัติ)

### ⚙️ ระบบจัดการหลังบ้านแอดมิน (Admin Panel)
* **ควบคุมสไลด์โชว์หน้าแรก:** เพิ่ม ลบ จัดลำดับ และกำหนดวันเริ่มต้น-สิ้นสุดการแสดงผลภาพแบนเนอร์ประชาสัมพันธ์
* **ระบบลงข่าวสารและสื่อประชาสัมพันธ์:** เขียนบทความ เลือกหมวดหมู่ อัปโหลดภาพแกลเลอรี และเอกสารแนบ PDF
* **ระบบจัดการสมาชิกบุคลากร:** จัดการรายชื่อบุคลากร ค้นหา ปรับเปลี่ยนสิทธิ์แอดมิน/ผู้ใช้งานทั่วไป และดูแลการเชื่อมโยงระบบเงินเดือน

## 🔒 มาตรการความปลอดภัยขั้นสูง (Security Hardening)

> [!IMPORTANT]
> ทุกกระบวนการแลกเปลี่ยนข้อมูลและการเข้าถึงหน้าเพจในแอปพลิเคชันนี้ ถูกออกแบบภายใต้หลักการความปลอดภัยสูงสุดเพื่อป้องกันช่องโหว่ทางเครือข่าย

* **Defensive Route Protection:** ทุกเพจที่สำคัญ (เช่น ระบบสมาชิก, อนุมัติงาน, หลังบ้านจัดการข่าว) ถูกบังคับตรวจสอบความถูกต้องของเซสชันที่ฝั่งเซิร์ฟเวอร์ (Server-side Session Checks) และทำการดีดกลับ (Server Redirect) ทันทีหากไม่มีเซสชันที่ถูกต้อง ป้องกันการเข้าถึงหน้าแสดงผลผ่าน URL โดยตรง
* **Cryptographic Session Signature:** คุกกี้เซสชันถูกลงลายมือชื่อดิจิทัลผ่านอัลกอริทึม HMAC-SHA256 โดยอิงจากรหัสลับในเซิร์ฟเวอร์เท่านั้น ป้องกันการโจมตีประเภท Session Tampering / Hijacking 100%
* **Preventing Database Leakage:** คำสั่งการสอบถามฐานข้อมูลทั้งหมดใช้กลไก Prepared Statements และ Parameterized Queries ผ่าน Prisma ORM ป้องกันช่องโหว่ SQL Injection พร้อมทั้งบล็อกการส่งข้อมูลโครงสร้างตารางหรือระบบไฟล์ผิดพลาดกลับไปยังบราวเซอร์ผู้ใช้ โดยแอปจะบันทึก Log ความผิดพลาดไว้ที่ฝั่งเซิร์ฟเวอร์และส่งเพียงรหัสข้อผิดพลาดทั่วไปกลับไปให้ผู้ใช้เท่านั้น

## 📂 โครงสร้างโฟลเดอร์หลัก (Project Structure)

```text
├── prisma/                    # prisma schema กำหนดโครงสร้างตารางข่าวสาร

├── storage/                   # โฟลเดอร์เก็บข้อมูลภายใน เช่น ลายมือชื่อดิจิทัลของบุคลากร
├── src/
│   ├── app/                   # Next.js Pages และ API Routes ทั้งหมด
│   │   ├── admin-news/        # หน้าระบบแอดมินจัดการข่าวสารและสไลด์โชว์
│   │   ├── api/               # ตัวประมวลผลข้อมูลหลังบ้าน (นัดหมาย, สมาชิก, เงินเดือน, ข่าว)
│   │   ├── check-date/        # บริการประชาชนสำหรับเช็คตารางนัดแพทย์
│   │   ├── member/            # บริการบุคลากร ล็อกอิน, เขียนใบขอสั่งผลิต, ลงนามอนุมัติใบงาน
│   │   ├── news/              # หน้ารายละเอียดและรวมรายการข่าวสารประชาสัมพันธ์ฝั่งประชาชน
│   │   └── service/           # หน้าห้องแล็บ, เครื่องมือตรวจสอบ และ ER Live Status
│   ├── components/
│   │   └── common/            # โครงร่าง UI ส่วนกลาง (Navbar, Footer, HeroSlideshow)
│   ├── config/                # ไฟล์ตั้งค่าสำหรับหน้าโฮมเพจและลิงก์ระบบภายใน
│   ├── features/              # โมดูลฟังก์ชันย่อยเฉพาะด้าน (เช่น ระบบภาพแกลเลอรี)
│   ├── lib/                   # โมดูลอำนวยความสะดวก (ฐานข้อมูลเชื่อมต่อ, เซสชัน, อัตรา Rate limits)
│   └── types/                 # ไฟล์ระบุประเภทข้อมูลสำหรับพัฒนาด้วย TypeScript
├── middleware.ts              # Next.js Middleware คัดกรองการเข้าถึงเส้นทางระดับหน้าบ้าน
├── next.config.ts             # ไฟล์กำหนดค่าคอมไพล์ของ Next.js และมาตรการ Security Headers
└── tsconfig.json              # ไฟล์ควบคุมการคอมไพล์ของภาษา TypeScript
```

## 🚀 วิธีเริ่มต้นใช้งานในฐานะนักพัฒนา (Getting Started)

### 1. ติดตั้งไลบรารีที่จำเป็น
เปิดโปรแกรมคอนโซลที่โฟลเดอร์โปรเจกต์แล้วรันคำสั่ง:
```bash
npm install
```

### 2. กำหนดค่าสภาพแวดล้อม (Environment Variables)
คัดลอกไฟล์ `.env.example` ไปสร้างเป็นไฟล์ใหม่ชื่อ `.env` ที่จุดโฟลเดอร์หลักของโปรเจกต์ จากนั้นกรอกข้อมูลการตั้งค่าให้สอดคล้องกับระบบของคุณ:
* กำหนด `DATABASE_URL` ชี้ไปที่ MySQL ฐานข้อมูลหลัก
* กำหนดที่อยู่ IP และพอร์ตสำหรับฐานข้อมูลเงินเดือน และระบบข้อมูลอื่น ๆ ของโรงพยาบาล
* กำหนดค่าการส่งอีเมลระบบยืนยันตัวตนสมาชิก (SMTP Gmail App Password)
* สร้างรหัสความปลอดภัยสำหรับสร้าง Token เช่น `MEMBER_SESSION_SECRET` และ `NEXTAUTH_SECRET` ด้วยคีย์ที่มีความยาวและซับซ้อนสูง

### 3. อัปเดตโครงสร้างตารางและสร้าง Client ฐานข้อมูล
```bash
npx prisma generate
```

### 4. เปิดระบบในโหมดสำหรับการพัฒนา (Development)
```bash
npm run dev
```
ระบบจะเปิดใช้งานและพร้อมให้เข้าทดสอบผ่านบราวเซอร์ที่เว็บบล็อก [http://localhost:3000](http://localhost:3000)

### 5. ทำการ Build และรันในโหมดใช้งานจริง (Production)
```bash
npm run build
npm run start
```
แอปพลิเคชันจะถูกคอมไพล์และสร้างหน้าเว็บแบบออปติไมซ์ประสิทธิภาพสูงสุดพร้อมเปิดรันใช้งานจริง
