# เทมเพลต Brief สำหรับสั่งออกแบบ UI (Mode B)

กรอกบริบทจริงของระบบโรงพยาบาลเถินในช่อง `[...]` ให้ครบก่อนส่งต่อให้ AI หรือดีไซเนอร์ ห้ามส่งเทมเพลตเปล่า

---

## ข้อความ Brief มาตรฐาน

```text
ช่วยออกแบบ/ปรับโฉมหน้า [ระบุชื่อหน้า เช่น รายงานคัดกรองสุขภาพ] สำหรับระบบโรงพยาบาลเถิน

1. บริบทระบบและผู้ใช้งาน:
- หน้าที่ของหน้า: [ระบุงานหลักที่ผู้ใช้เข้ามาทำ]
- ผู้ใช้งานหลัก: [ระบุ เช่น เจ้าหน้าที่เวชระเบียน/การเงิน หรือ ประชาชน/ผู้สูงอายุ]
- บริบทการแสดงข้อมูลส่วนบุคคล (PHI): [เลือกอย่างใดอย่างหนึ่ง:
  (ก) หน้าสาธารณะ/ทั่วไป -> Mask เลขบัตรและ HN เหลือ 4 หลักท้าย
  (ข) พอร์ทัลภายใน RCM -> แสดงเลขบัตร 13 หลักและ HN/VN เต็มเพื่อกระทบยอด e-Claim]
- Stack: Next.js 16 (App Router), React 19, CSS Modules / page.css ใช้ CSS Variables จาก globals.css

2. ปัญหาของหน้าเดิมที่ต้องแก้:
- [เช่น หน้าจอแน่นอึดอัด การ์ด 8 ใบหน้าตาซ้ำกันหมดจนไม่รู้ว่าเลขไหนสำคัญ]
- [เช่น แถบตัวกรองตัดขึ้นหลายบรรทัด ตารางเอียงไม่ตรงหัวข้อ]

3. ทิศทางงานออกแบบ (Quiet Chrome, Rich Content — ไม่ดูเป็นเทมเพลต AI):
- บุคลิก: สงบ แม่นยำ สะอาดตา เหมือนแฟ้มเวชระเบียนสมัยใหม่ที่จ้องทำงานทั้งวันแล้วไม่ล้าตา
- สีและพื้นผิว: Neutral Ramp จาก globals.css (#FAFCFB พื้นหลัก, #FFFFFF การ์ด, #E2E8E4 เส้นขอบบาง); ใช้สีเขียวหลัก (#0D7446) เฉพาะจุดนำสายตา (Primary Button 1 ปุ่ม, Active Tab, Focus Ring) และใช้สีสถานะ 1 สี = 1 ความหมาย (คอนทราสต์ >= 4.5:1)
- ตัวอักษร: Sarabun น้ำหนัก 400 / 500 / 600 (เลี่ยง 700-900 พร่ำเพรื่อ), ระยะบรรทัด 1.6-1.7, ตัวเลขทุกจุดใช้ tabular-nums
- ระยะห่าง (4px Grid): Card padding 20-24px, Section gap 24-32px, แถวตารางสูง >= 52-56px, เป้าสัมผัส >= 44-48px
- ลำดับความสำคัญและโครงสร้าง:
  - จัดสัดส่วนให้มีน้ำหนัก (เช่น สรุปยอดหลัก 2-4 ตัว + แถบ Filter Chips กระชับ แทนการวางการ์ดหน้าตาเหมือนกัน 8 ใบ; หากมีกราฟ ให้ใช้กราฟหลัก 1 ชิ้นเท่านั้น)
  - แถบเลือกช่วงเวลาเรียงบรรทัดเดียว: [กำหนดเอง | เดือน | ปีงบประมาณ] + ตัวเลือกวันที่คั่นด้วยเส้นตั้งบาง
  - ช่องค้นหา 1 ช่องครอบคลุมทุกฟิลด์ (HN, CID, ชื่อ-สกุล, VN/AN, รหัสโรค, สิทธิ) ไม่มีดรอปดาวน์เลือกฟิลด์
- มาตรฐานตาราง:
  - th และ td จัดแนวตรงกัน 100% (จัดกึ่งกลางเป็นหลักสำหรับ ลำดับ, วันที่/เวลา, HN, CID, ชื่อ-สกุลแกน X, อายุ, สถานะ Badge, จำนวนนับ, ชดเชย)
  - ไอคอน Sort อยู่บรรทัดเดียวกับชื่อหัวข้อ (inline-flex + nowrap)
  - ชื่อ-สกุลยกไปทั้งนามสกุลเมื่อจอแคบ; อายุและ "ปี" อยู่บรรทัดเดียวกัน
  - คลิกทั้งแถว (tr) เพื่อเปิด Modal รายละเอียดได้โดยตรง

4. ข้อห้ามเพื่อกันงานสไตล์ AI Template:
- ห้าม Emoji, ห้ามเครื่องหมายตกใจ (!), ห้ามไอคอนตกแต่งลอยๆ ที่ไม่มีหน้าที่
- ห้าม Gradient สีแฟนซี, แสง Glow, Glassmorphism, แถบสีหนาขอบซ้ายการ์ด, แท่งกราฟสีรุ้ง
- ห้าม Eyebrow Pill Badge ลอยเหนือ <h1> และห้ามใส่เลขลำดับ (1. 2. 3.) หน้าชื่อเมนู หัวข้อหน้า หรือแท็บวันที่
- ห้ามใส่วงเล็บช่วงวันที่ต่อท้ายตัวเลือกปีงบประมาณ/เดือน
- ห้ามใส่ปุ่ม Copy ในเซลล์ตาราง และห้ามใส่ Tag ช่วงอายุแปะข้างข้อมูลปกติ
- ห้ามใช้ transition: all, hover:scale บนการ์ด หรือ animate-pulse บนกล่องที่ไม่ได้กำลังโหลด

5. มาตรฐานข้อมูลและผลลัพธ์:
- วันที่แสดงเป็น พ.ศ. ไทยเสมอ
- ครบทั้ง 4 สถานะ: Empty, No Search Results, Loading Skeleton, Error ภาษาไทยสุภาพ
- ส่งมอบ: (1) Interactive Prototype หรือโค้ดจริง (2) Design Spec (.md) (3) หมายเหตุแยกส่วนข้อมูลจริง vs Placeholder
```
