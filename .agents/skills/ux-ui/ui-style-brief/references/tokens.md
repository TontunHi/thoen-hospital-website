# Design Tokens & CSS Variables (โรงพยาบาลเถิน)

อิงตามค่าตัวแปรใน `src/app/globals.css` โดยตรง เพื่อให้โค้ดจริงและต้นแบบใช้ตัวแปรชุดเดียวกัน

---

## 1. สีแบรนด์และพื้นผิวหลัก (Core Surfaces & Brand)

| Token (CSS Variable) | ค่าสี HEX | การใช้งาน |
|---|---|---|
| `var(--primary)` | `#0D7446` | สีเขียวหลักของโรงพยาบาล, ปุ่มหลัก (Primary Button), แท็บที่เลือก, Focus ring |
| `var(--primary-hover)` | `#0B633C` | สี hover ของปุ่มหลัก |
| `var(--primary-light)` | `#E8F5E9` | พื้นหลังปุ่มรอง, พื้นแถบเน้น, ป้ายบอกจำนวนสถานะ |
| `var(--primary-subtle)` | `#F0FDF4` | พื้นแถวที่เลือก (Selected row) หรือแถวอันดับ 1 |
| `var(--bg-main)` | `#FAFCFB` | พื้นหลังของหน้าเว็บทั้งระบบ |
| `var(--bg-surface)` | `#FFFFFF` | พื้นผิวการ์ด, ตาราง, กล่องข้อความ, โมดอล |
| `var(--bg-subtle)` | `#F4F7F5` | แถบหัวตาราง, พื้นแถบสรุปข้อมูล |

## 2. โทนสีข้อความและเส้นขอบ (Ink & Borders)

| Token (CSS Variable) | ค่าสี HEX | การใช้งาน |
|---|---|---|
| `var(--gray-900)` | `#111E14` | ข้อความหลัก (Heading & Body text สำคัญ) |
| `var(--gray-700)` | `#334237` | ข้อความรอง (Secondary description) |
| `var(--gray-500)` | `#6B7B70` | ป้ายกำกับย่อย, คำอธิบายกำกับ (คอนทราสต์ ≥ 4.5:1 บนพื้นขาว) |
| `var(--gray-200)` | `#E2E8E4` | เส้นขอบการ์ด, ขอบกล่อง input |
| `var(--gray-100)` | `#F1F5F3` | เส้นคั่นแถวในตาราง (Row divider) |

## 3. สีสื่อความหมายและสถานะ (Semantic Status Colors)

**กฎเหล็ก:** 1 สี = 1 ความหมาย ห้ามใช้สีตกแต่ง ทุกสถานะต้องมีข้อความกำกับเสมอ

| สถานะ | พื้นหลัง | ตัวอักษร | เส้นขอบ | ความหมาย |
|---|---|---|---|---|
| **ปกติ / สำเร็จ** | `var(--success-bg)` (`#DCFCE7`) | `var(--success)` (`#15803D`) | `var(--success-border)` (`#86EFAC`) | เสร็จสิ้น, อนุมัติแล้ว, ออนไลน์ |
| **เตือน / รอดำเนินการ** | `var(--warning-bg)` (`#FEF3C7`) | `var(--warning)` (`#B45309`) | `var(--warning-border)` (`#FDE68A`) | รอคิว, รออนุมัติ, ต้องตรวจสอบ |
| **เสี่ยง / ปฏิเสธ / ยกเลิก** | `var(--danger-bg)` (`#FEE2E2`) | `var(--danger)` (`#B91C1C`) | `var(--danger-border)` (`#FCA5A5`) | ปฏิเสธ, ข้อผิดพลาด, ยอดหนี้/ความเสี่ยง |
| **ข้อมูลทั่วไป / ดูอย่างเดียว** | `var(--info-bg)` (`#E0F2FE`) | `var(--info)` (`#0369A1`) | `var(--info-border)` (`#BAE6FD`) | เอกสารเผยแพร่, ข้อมูลทั่วไป |

## 4. ตัวอักษร (Typography)

| รายการ | ค่าที่ใช้ |
|---|---|
| **ฟอนต์หลัก** | `var(--font-family)` (Sarabun / `var(--font-sarabun)`) |
| **ฟอนต์โค้ด / รหัส / ตัวเลขตาราง** | `font-variant-numeric: tabular-nums` (ตัวเลขหลักตรงกัน ไม่แกว่ง) |
| **ข้อความหลัก (Base)** | `1rem` (16px), `line-height: 1.6 - 1.7` (ภาษาไทยต้องการช่องว่างบรรทัดพอเหมาะ) |
| **หัวข้อ H1** | `1.875rem - 2.25rem` (30-36px), หนา 600-700 |
| **หัวข้อ H2** | `1.5rem` (24px), หนา 600 |
| **ป้ายกำกับ / คำอธิบายย่อย** | `0.8125rem` (13px) – **ห้ามต่ำกว่า 12px** เพื่อความสะดวกในการอ่านของผู้ป่วย/ผู้สูงอายุ |
| **ข้อควรระวังภาษาไทย** | ห้ามใส่ `letter-spacing` กับตัวอักษรไทย, ใช้ `overflow-wrap: break-word` |

## 5. รูปทรงและระยะสัมผัส (Spacing, Radius & Touch Target)

| รายการ | ค่ามาตรฐาน |
|---|---|
| **เป้าสัมผัส (Touch Target)** | ปุ่มกดและ Input ต้องมีความสูง ≥ **44px** เสมอ (รองรับผู้ใช้งานบนมือถือ PWA) |
| **รัศมีมุม (Border Radius)** | การ์ด/กล่อง: `12px`, ปุ่ม/Input: `8px`, ป้ายสถานะ/Badge: `6px` |
| **เงา (Box Shadows)** | เงาเรียบเนียน ไม่หนาลอย: `var(--shadow-card)` หรือ `var(--shadow-sm)` ห้ามเงาสีดำหนาทึบ |
| **ความกว้างเนื้อหา** | Max width `1200px` จัดกึ่งกลางหน้าจอ, มี padding ขอบจออย่างน้อย `16px - 24px` |
| **Safe Area Inset** | สำหรับแถบ Action ติดขอบจอล่างบนมือถือ: `padding-bottom: env(safe-area-inset-bottom)` |
