# Design tokens (ค่าเริ่มต้น)

ใช้ชุดนี้เป็นค่าเริ่มต้นสำหรับเว็บโรงพยาบาล ถ้าผู้ใช้มีแบรนด์/สีหลักอื่น ให้เปลี่ยนเฉพาะ accent และรักษากติกาเดิม

## สีพื้นฐาน

| Token | ค่า | ใช้กับ |
|---|---|---|
| bg | `#f6f7f5` | พื้นหลังหน้า |
| surface | `#ffffff` | การ์ด ตาราง input |
| surface-alt | `#fafbf9` | แถวหัวตาราง แถบ legend |
| border | `#e3e7e2` | ขอบการ์ด |
| border-input | `#cfd6d0` | ขอบ input / select / ปุ่มรอง |
| row-divider | `#eef1ee` | เส้นคั่นแถว |
| ink | `#14201a` | ข้อความหลัก |
| ink-2 | `#33423a` | ข้อความรอง |
| muted | `#5d6b63` | ป้ายกำกับ คำอธิบาย (≥ 4.5:1 บนขาว) |
| accent | `#0b6b47` | ปุ่มหลัก แท็บ/แถวที่เลือก focus ring |
| accent-dark | `#084d34` | hover, ข้อความบนพื้น accent-tint |
| accent-tint | `#e8f3ee` | พื้นปุ่มรอง แถวที่เลือก ป้ายจำนวน |
| accent-row | `#f3f9f6` | พื้นแถวเด่น (เช่น อันดับ 1) |

## สีที่สื่อความหมาย (ใช้ได้เมื่อมีประเภทข้อมูลให้แยกเท่านั้น)

พื้นอ่อน + ตัวอักษรเข้มโทนเดียวกัน ทุกคู่คอนทราสต์ ≥ 4.5:1

| โทน | พื้น | ตัวอักษร | จุด/ขอบ | ตัวอย่างความหมาย |
|---|---|---|---|---|
| ฟ้า | `#e6f0fb` | `#17467a` | `#2f6fb5` | ระดับต่ำสุด/ดูอย่างเดียว |
| เหลืองอำพัน | `#fdf1d6` | `#6b4100` | `#c98a10` | ระดับกลาง/ต้องระวัง |
| ชมพู | `#fbe6ea` | `#8f1d3a` | `#c43d5c` | ความเสี่ยง/ข้อจำกัด/ระดับตัดสินใจ |
| ม่วง | `#efe8fb` | `#502a8f` | `#7b52c9` | ระดับสูงสุด/ผู้ดูแล |
| ม่วงอินดิโก | `#eef0fb` | `#2b3a8c` | `#d5d9f2` | ประเภท "ตำแหน่ง/กลุ่ม" |
| เขียวน้ำทะเล | `#e8f6f4` | `#0f5c53` | `#cdebe6` | ประเภท "บุคคล" |
| เทาอมฟ้า | `#e8edf3` | `#2f4156` | | กลุ่มระบบ/หมวดรอง |

## กติกาการใช้สี

| ข้อ | กติกา |
|---|---|
| 1 สี = 1 ความหมาย | ห้ามใช้สีเดียวกันกับสองความหมาย ห้ามใช้สีตกแต่ง |
| ไม่พึ่งสีอย่างเดียว | ทุกสีมีตัวอักษรกำกับ |
| จำนวนสี | ถ้าความหมายเกิน 2 ประเภท ให้มีแถบ legend |
| ไล่ตามน้ำหนัก | เรียงจากเบาไปหนักตามความสำคัญ/ความเสี่ยง ชมพูสงวนไว้กับความเสี่ยงหรือข้อจำกัด |
| ห้าม | gradient, glow, เงาหนา, สีสดเต็มพื้น, ขอบสีด้านซ้ายของการ์ด |
| โหมดมืด (ถ้าขอ) | คงความหมายสีเดิม สลับเป็นพื้นเข้ม + ตัวอักษรอ่อนโทนเดียวกัน ตรวจคอนทราสต์ใหม่ |

## ตัวอักษร

| ส่วน | ค่า |
|---|---|
| ฟอนต์ | IBM Plex Sans Thai (400/500/600) fallback `system-ui, sans-serif` รหัส/คีย์ใช้ IBM Plex Mono |
| ฐาน | 15px, line-height 1.6 (ไทยต้องการบรรทัดสูง) |
| h1 | 32px/600, line-height 1.3 |
| h2 | 22px/600 |
| ตัวเลขเด่น | 26-40px/600 |
| ป้ายกำกับ ข้อความย่อย | 13px (ห้ามต่ำกว่า 12px) |
| ตัวเลขในตาราง | `font-variant-numeric: tabular-nums` |
| ข้อควรระวังภาษาไทย | ไม่ใส่ letter-spacing กับข้อความไทย ไม่ตัดชื่อด้วย "..." ถ้าเลี่ยงได้ ให้ขึ้นบรรทัดใหม่ ใช้ `overflow-wrap:anywhere` กับข้อความที่อาจยาวไม่มีช่องว่าง |

## ระยะและรูปทรง

| รายการ | ค่า |
|---|---|
| สเกลระยะ | 4, 8, 12, 16, 24, 32, 48, 64 |
| ความกว้างเนื้อหา | 1080px (หน้า 2 คอลัมน์ 1160px) จัดกึ่งกลาง |
| padding หน้า | 32px บน 24px ข้าง 64px ล่าง |
| รัศมีมุม | การ์ด 12px, input/ปุ่ม 8px, ป้าย 6px, ชิป 8px |
| เงา | ไม่ใช้ หรือเงาบางมาก `0 1px 2px rgba(20,32,26,.12)` เฉพาะแท็บที่เลือก |
| เป้าสัมผัส | ปุ่ม/input สูง ≥ 44px (ปุ่ม × ในชิป ≥ 32px) |
| Focus | outline 2px accent offset 2px บนทุก element ที่โฟกัสได้ |
| Motion | น้อยที่สุด ≤ 150ms เคารพ `prefers-reduced-motion` ไม่มีแอนิเมชันตกแต่ง |
