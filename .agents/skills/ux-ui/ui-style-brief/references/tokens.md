# Design Tokens & CSS Variables (โรงพยาบาลเถิน)

อิงตามค่าตัวแปรใน `src/app/globals.css` โดยตรง เพื่อให้โค้ดจริงและต้นแบบใช้ตัวแปรชุดเดียวกันอย่างสมบูรณ์

---

## 1. สีแบรนด์และพื้นผิวหลัก (Core Surfaces & Brand)

| Token (CSS Variable) | ค่าสี HEX | การใช้งาน & ความรู้สึก |
|---|---|---|
| `var(--primary)` | `#0D7446` | สีเขียวหลักของโรงพยาบาล สื่อถึงสุขภาพ ความปลอดภัย และความน่าเชื่อถือ ใช้กับปุ่มหลัก (Primary Button), แท็บที่เลือก, Focus ring |
| `var(--primary-hover)` | `#0B633C` | สี hover ของปุ่มหลัก เข้มขึ้นเล็กน้อยเพื่อยืนยันการโต้ตอบ |
| `var(--primary-dark)` | `#095C38` | สี active ขณะกดปุ่ม |
| `var(--primary-light)` | `#E8F5E9` | พื้นหลังปุ่มรอง, พื้นแถบเน้น, ป้ายบอกจำนวนสถานะ |
| `var(--primary-subtle)` | `#F0FDF4` | พื้นแถวที่เลือก (Selected row), กล่องสรุปไฮไลท์ ให้ความรู้สึกสบายตา |
| `var(--bg-main)` | `#FAFCFB` | พื้นหลังของหน้าเว็บทั้งระบบ เป็นสีขาวอมเขียวจางๆ ช่วยลดแสงสะท้อนและไม่ล้าสายตา |
| `var(--bg-surface)` | `#FFFFFF` | พื้นผิวการ์ด, ตาราง, กล่องข้อความ, โมดอล สะอาดและแยกชั้นชัดเจน |
| `var(--bg-subtle)` | `#F4F7F5` | แถบหัวตาราง, พื้นแถบสรุปข้อมูล, กล่องตัวกรอง |
| `var(--accent-gold)` | `#C8A835` | สีทองประจำอัตลักษณ์โรงพยาบาลเถิน ใช้เน้นจุดสำคัญพิเศษหรือตราสัญลักษณ์ |
| `var(--accent-gold-dark)` | `#8C6D1F` | สีตัวอักษรทองเข้มบนพื้นสว่าง (คอนทราสต์ ≥ 4.5:1 ตามเกณฑ์ A7) |

## 2. โทนสีข้อความและเส้นขอบ (Ink & Borders)

| Token (CSS Variable) | ค่าสี HEX | การใช้งาน |
|---|---|---|
| `var(--gray-900)` | `#111E14` | ข้อความหลัก (Heading & Body text สำคัญ) คมชัด อ่านง่ายสูงสุด |
| `var(--gray-700)` | `#334237` | ข้อความรอง (Secondary description) อ่านสบายตา ไม่ทึบเกินไป |
| `var(--gray-500)` | `#6B7B70` | ป้ายกำกับย่อย, คำอธิบายกำกับ (คอนทราสต์ ≥ 4.5:1 บนพื้นขาว) |
| `var(--gray-200)` | `#E2E8E4` | เส้นขอบการ์ด, ขอบกล่อง input ให้มิติเส้นแบ่งที่ไม่บาดสายตา |
| `var(--gray-100)` | `#F1F5F3` | เส้นคั่นแถวในตาราง (Row divider) ช่วยแยกบรรทัดให้อ่านง่าย |

## 3. สีสื่อความหมายและสถานะ (Semantic Status Colors)

**กฎเหล็ก:** 1 สี = 1 ความหมาย ทุกสถานะต้องมีข้อความกำกับเสมอเพื่อช่วยผู้ที่มีภาวะตาบอดสี

| สถานะ | พื้นหลัง | ตัวอักษร | เส้นขอบ | ความหมาย & ตัวอย่าง |
|---|---|---|---|---|
| **ปกติ / สำเร็จ** | `var(--success-bg)` (`#DCFCE7`) | `var(--success)` (`#15803D`) | `var(--success-border)` (`#86EFAC`) | เสร็จสิ้น, อนุมัติแล้ว, พร้อมให้บริการ, ออนไลน์ |
| **เตือน / รอดำเนินการ** | `var(--warning-bg)` (`#FEF3C7`) | `var(--warning)` (`#B45309`) | `var(--warning-border)` (`#FDE68A`) | รอคิว, รอแพทย์ตรวจ, รออนุมัติ, ต้องยืนยันตัวตน |
| **เสี่ยง / ปฏิเสธ / ยกเลิก** | `var(--danger-bg)` (`#FEE2E2`) | `var(--danger)` (`#B91C1C`) | `var(--danger-border)` (`#FCA5A5`) | ปฏิเสธ, ยกเลิก, ข้อผิดพลาด, เกินกำหนด |
| **ข้อมูลทั่วไป / ชี้แจง** | `var(--info-bg)` (`#E0F2FE`) | `var(--info)` (`#0369A1`) | `var(--info-border)` (`#BAE6FD`) | ข้อมูลประชาสัมพันธ์, เอกสารเผยแพร่, คำแนะนำ |

## 4. ตัวอักษรและระยะบรรทัด (Typography & Readability)

| รายการ | Token / ค่าที่ใช้ | คำแนะนำสำหรับการใช้งานจริง |
|---|---|---|
| **ฟอนต์หลัก** | `var(--font-family)` | Sarabun (ฟอนต์ทางการที่คนไทยคุ้นเคย อ่านง่ายที่สุด) |
| **ฟอนต์ตัวเลขตาราง** | `font-variant-numeric: tabular-nums` | บังคับใช้กับตาราง, ยอดเงิน, วันที่, และเวลา เพื่อให้หลักตรงกันเสมอ |
| **ความสูงบรรทัด (Line Height)** | `1.6 - 1.7` (`line-height: 1.7`) | ห้ามบีบบรรทัดชิดกัน ภาษาไทยมีสระบน-ล่าง ต้องการพื้นที่ระบายตา |
| **หัวข้อหน้า (H1)** | `1.875rem - 2.25rem` (30-36px) หนา 600-700 | เด่นชัด ช่วยให้ผู้ใช้รู้ทันทีว่าอยู่ที่ไหนในระบบ |
| **หัวข้อส่วนย่อย (H2)** | `1.5rem` (24px) หนา 600 | แยกสัดส่วนเนื้อหา |
| **ข้อความหลัก (Base Body)** | `1rem` (16px) | ขนาดมาตรฐาน ไม่เล็กเกินไปสำหรับผู้สูงอายุ |
| **ป้ายกำกับ / คำแนะนำ (Small)** | `0.875rem` (14px) | คำอธิบายกำกับใต้ฟิลด์หรือคำแนะนำย่อย |
| **ขนาดเล็กสุด (Micro)** | `0.8125rem` (13px) | **ห้ามต่ำกว่า 13px เด็ดขาด** เพื่อความสะดวกของสายตาผู้ใช้ทั่วไป |

## 5. ระยะห่างและความโปร่งสบาย (Breathing Room & Spacing Scale)

**กฎสำคัญ: ห้ามบีบอัดข้อมูลจนแน่นอึดอัด** เว้นระยะห่างให้สบายตาตามมาตราส่วน:

| Token | ค่า REM / PX | การใช้งานที่แนะนำ |
|---|---|---|
| `var(--space-2)` | `0.5rem` (8px) | ช่องว่างระหว่างไอคอนกับข้อความ, Padding ป้าย Badge |
| `var(--space-3)` | `0.75rem` (12px) | ช่องว่างระหว่างปุ่มแนวนอน, Gap ภายในกลุ่มตัวเลือก |
| `var(--space-4)` | `1rem` (16px) | Padding ขอบจอมือถือ, Gap ระหว่างฟิลด์ในฟอร์ม |
| `var(--space-6)` | `1.5rem` (24px) | **Padding ภายในการ์ด (Card Padding)**, Gap ระหว่างหัวข้อกับเนื้อหา |
| `var(--space-8)` | `2rem` (32px) | **ระยะห่างระหว่างกลุ่มเนื้อหา (Section Gap)** ช่วยให้ผู้ใช้พักสายตา |
| `var(--space-12)` | `3rem` (48px) | ระยะห่างส่วนบน-ล่างของหน้าหลัก |

## 6. มิติความลึก รัศมี และเป้าสัมผัส (Elevation, Radius & Touch Target)

| รายการ | ค่ามาตรฐาน | เหตุผลด้าน UX |
|---|---|---|
| **เป้าสัมผัส (Touch Target)** | สูงอย่างน้อย **44px - 48px** (`min-height: 44px`) | เพื่อให้ผู้สูงอายุและคนทั่วไปกดง่าย ไม่กดย้วยหรือกดพลาด |
| **รัศมีมุม (Radius)** | การ์ด/คอนเทนเนอร์: `12px - 16px` (`var(--radius-lg)`)<br>ปุ่ม/Input: `8px` (`var(--radius)`)<br>ป้าย Badge: `9999px` (Pill shape) | มุมโค้งมนละมุนตา ลดความแข็งกระด้างของระบบราชการ |
| **เงาการ์ด (Card Shadow)** | `var(--shadow-card)`: `0 1px 3px rgba(13, 116, 70, 0.05), 0 4px 12px rgba(13, 116, 70, 0.04)` | มิตินุ่มลึกโทนเขียวจาง สะอาดสะอ้าน เป็นธรรมชาติ |
| **เงา Hover (Hover Shadow)** | `var(--shadow-hover)`: `0 6px 20px rgba(13, 116, 70, 0.09), 0 2px 6px rgba(13, 116, 70, 0.04)` | ยกตัวเบาๆ ให้การตอบสนองที่ชัดเจนเมื่อชี้ |
| **แอนิเมชันตอบสนอง** | `transition: all var(--transition-fast)` (150ms cubic-bezier) | ตอบสนองทันที นุ่มนวล ไม่กระตุกตา |
