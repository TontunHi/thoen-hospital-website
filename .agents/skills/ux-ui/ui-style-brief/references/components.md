# โครงสร้างและรูปแบบคอมโพเนนต์ (Component Guidelines)

สำหรับระบบโรงพยาบาลเถิน (Next.js 16 + CSS Modules / `page.css`)

---

## 1. ลำดับโครงสร้างหน้ามาตรฐาน (Standard Page Layout)

| ลำดับ | ส่วนประกอบ | รายละเอียดการจัดวาง |
|---|---|---|
| **1** | ลิงก์ย้อนกลับ | ข้อความ `← กลับสู่หน้ารายการ` ตัวอักษรสี `var(--gray-700)` สูง ≥ 44px |
| **2** | ส่วนหัว (Header Bar) | `<h1>` ชื่อหน้า + คำอธิบายสั้น 1 บรรทัด + **ปุ่มหลักของหน้า (ชิดขวา)** |
| **3** | แถบสรุปตัวเลข (Summary Bar) | รวมยอดสถิติในแถบเดียว (เช่น "ทั้งหมด 24 / รอดำเนินการ 5 / เสร็จสิ้น 19") ไม่แยกเป็นการ์ดเล็กหลายใบ |
| **4** | แถบเครื่องมือ (Toolbar) | ซ้าย: แถบแท็บกรองสถานะ \| ขวา: ช่องค้นหาแบบ Live + ดรอปดาวน์คัดกรอง |
| **5** | เนื้อหาหลัก (Main Content) | ตารางข้อมูล (Table) หรือการ์ดรายการกลุ่ม (Grouped Cards) |

---

## 2. กติกาคอมโพเนนต์หลัก

| คอมโพเนนต์ | แนวทางปฏิบัติ |
|---|---|
| **ปุ่มหลัก (Primary Button)** | พื้นหลัง `var(--primary)`, ตัวอักษรขาว, สูงอย่างน้อย 44px, **มีเพียง 1 ปุ่มต่อมุมมองหลัก** |
| **ปุ่มรอง (Secondary Button)** | พื้นหลังขาว ขอบ `var(--gray-200)` หรือพื้น `var(--primary-light)` ข้อความสีเขียวเข้ม |
| **ปุ่มอันตราย (Destructive Button)** | พื้นหลัง `var(--danger-bg)` ตัวอักษร `var(--danger)` ใช้เฉพาะปุ่มลบหรือถอนสิทธิ์ |
| **แท็บ (Tabs)** | แบบ Segmented Control (พื้นหลัง `var(--gray-100)`) หรือแบบขีดเส้นใต้ มีตัวเลขจำนวนกำกับหลังชื่อแท็บ |
| **ช่องค้นหา (Search Input)** | `input[type="search"]` ระบุ placeholder ชัดเจน ("ค้นหาด้วยชื่อ, HN หรือเลขบัตร...") ค้นหาแบบ Realtime |
| **ตารางข้อมูล (Data Table)** | หุ้มด้วยกล่อง `overflow-x: auto`, หัวตารางพื้น `var(--bg-subtle)`, ตัวเลขใช้ `font-variant-numeric: tabular-nums` ชิดขวา, แถวสูง ≥ 48px |
| **ป้ายสถานะ (Status Badge)** | ใช้โทนสีอ่อน + ตัวอักษรเข้มตาม `tokens.md`, แสดงเฉพาะสถานะที่สำคัญหรือแตกต่าง ไม่ใส่ป้ายซ้ำทุกแถว |
| **ฟอร์มกรอกข้อมูล (Forms)** | Label อยู่เหนือ Input เสมอ (ห้ามใช้ placeholder แทน Label), ข้อความ error สีแดงอยู่ใต้ช่องพร้อมวิธีแก้ |
| **โมดอลยืนยัน (Confirmation Modal)** | ใช้เฉพาะการกระทำที่ย้อนกลับไม่ได้ ระบุชื่อสิ่งที่กำลังกระทำชัดเจน (เช่น "ต้องการลบข้อมูลสิทธิ์ของ ... หรือไม่?") |

## 3. สถานะที่ต้องมีในทุกหน้า (Required States)

1. **ว่าง (Empty State):** แสดงเมื่อยังไม่มีข้อมูล บอกสาเหตุชัดเจน ("ยังไม่มีประวัติการยืมอุปกรณ์") พร้อมปุ่มเริ่มสร้างใหม่
2. **ไม่พบผลการค้นหา (No Search Results):** แจ้งคำค้นที่ระบุ ("ไม่พบข้อมูลที่ตรงกับคำว่า '[คำค้น]'") พร้อมปุ่มล้างตัวกรอง
3. **กำลังโหลด (Loading Skeleton):** ใช้ Skeleton Box สีเทาอ่อนกะพริบเบาๆ ขนาดเท่าตาราง/การ์ดจริง ห้ามใช้ Spinner โดดๆ กลางจอ
4. **ข้อผิดพลาด (Error State):** แจ้งสาเหตุสุภาพ ไม่แสดง Raw error หรือ Stack trace แก่ผู้ใช้ พร้อมปุ่ม "ลองใหม่อีกครั้ง"

---

## 4. รองรับการใช้งานบนมือถือ (Mobile & PWA Ready)

- **Touch Target:** ทุกจุดคลิกและสัมผัสมีพื้นที่อย่างน้อย `44px x 44px`
- **Safe Area Insets:** แถบปุ่มติดขอบจอด้านล่าง (Sticky Bottom Bar) ต้องมี `padding-bottom: calc(12px + env(safe-area-inset-bottom))`
- **Responsive Layout:** ตารางกว้างให้เลื่อนแนวนอนเฉพาะตัวตาราง หรือปรับเป็นการ์ดรายบุคคลเมื่อความกว้างหน้าจอ < 768px
