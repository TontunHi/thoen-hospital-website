# เช็กลิสต์ก่อนส่งงาน

## 1. AI slop (ต้องไม่มี)

| อาการ | ตรวจ |
|---|---|
| ไอคอนหน้าทุกการ์ด/ทุกแถว | ไม่มีไอคอนตกแต่ง |
| emoji ในหัวข้อหรือข้อความ ("ยินดีต้อนรับ 👋") | ไม่มี |
| gradient ม่วง-น้ำเงิน, glow, glassmorphism | ไม่มี |
| การ์ดมีขอบสีด้านซ้าย | ไม่มี |
| ทุกมุม rounded-2xl + เงาหนาเท่ากันหมด | ไม่มี |
| ป้ายสี (pill) ซ้ำทุกแถว | ไม่มี |
| การ์ดสถิติ 3-4 ใบแยกกันโดยไม่มีประโยชน์ | รวมเป็นแถบเดียว หรือตัดทิ้งถ้าไม่ใช้ตัดสินใจ |
| ข้อความ lorem ipsum หรือข้อมูลที่ดูจริงแต่แต่งขึ้น | ใช้ข้อมูลจากภาพ หรือ placeholder ติดป้าย |
| hero ตรงกลางที่มีคำโปรยทั่วไป | ไม่มี หน้าใช้งานต้องเข้าเรื่องทันที |
| สีสุ่มเพื่อให้ดูมีชีวิต | ทุกสีมีความหมายและมีตัวอักษรกำกับ |

## 2. ใช้งานได้จริง

| ข้อ | ตรวจ |
|---|---|
| การกระทำหลักของหน้าเห็นได้ใน 3 วินาที | ✔ |
| แต่ละแถว/การ์ดมีปุ่มหลักไม่เกิน 1 | ✔ |
| ชื่อ/ข้อความยาวไม่ถูกตัดด้วย "..." และไม่ล้นกล่อง | ✔ |
| กรณีขอบถูกจัดการ (เท่ากัน ว่าง 1 รายการ เยอะมาก) | ✔ |
| สถานะ empty/โหลด/ผิดพลาด ออกแบบแล้ว | ✔ |
| แท็บ ค้นหา ตัวกรองในต้นแบบทำงานจริง | ✔ |
| ศัพท์สอดคล้องกันทั้งหน้า | ✔ |
| การกระทำเสี่ยงมีการยืนยันหรือเลิกทำ | ✔ |

## 3. เข้าถึงได้

| ข้อ | ตรวจ |
|---|---|
| คอนทราสต์ข้อความ ≥ 4.5:1 ทุกคู่สี (รวมข้อความบนพื้นสีอ่อน) | ✔ |
| ไม่พึ่งสีอย่างเดียว | ✔ |
| ใช้ `<button>` และ `<a>` จริง ไม่ใช้ `div` + onClick | ✔ |
| ทุก input มีป้ายหรือ `aria-label` | ✔ |
| focus เห็นชัด ใช้คีย์บอร์ดครบ | ✔ |
| เป้าสัมผัส ≥ 44px | ✔ |
| ขนาดตัวอักษรไม่ต่ำกว่า 12px (ข้อความอ่านจริง ≥ 13px) | ✔ |

## 4. ความซื่อสัตย์ของการส่งมอบ

| ข้อ | ตรวจ |
|---|---|
| ระบุว่าอะไรเป็น placeholder | ✔ |
| ระบุว่าอะไรทำงานเฉพาะในต้นแบบ ไม่ได้เชื่อมระบบ | ✔ |
| ระบุส่วนที่ไม่เห็นในภาพจึงยังไม่ได้ออกแบบ | ✔ |
| ยังไม่ได้เปิดดูผลลัพธ์จริง ให้บอกตรง ๆ แทนที่จะอ้างว่าตรวจแล้ว | ✔ |
| spec `.md` ตรงกับต้นแบบทุกจุด (สี ขนาด พฤติกรรม) | ✔ |
