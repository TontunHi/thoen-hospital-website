## 2. Anti-AI-Slop & Smart Subtraction Audit

| หมวด | สิ่งที่ตรวจ | เกณฑ์ผ่าน |
|---|---|---|
| **Quiet Chrome** | สีพื้น, เส้นขอบ, เงา | พื้นหลังเป็น Neutral Ramp (`#FAFCFB` / `#FFFFFF`), ไม่มี Gradient ม่วง-น้ำเงิน, ไม่มี Glow สี, ไม่มี Glassmorphism ฟุ้งๆ, **ไม่มีแถบขอบสีหนา 4px บนหัวหรือซ้ายการ์ด** |
| **Off-Black Ink** | สีข้อความ | ใช้หมึก Off-Black (`#111E14` สำหรับหัวข้อ/ตัวเลขหลัก, `#334237` สำหรับข้อความทั่วไป) **ห้ามใช้สีดำสนิท `#000000` บนพื้นขาว** |
| **Accent Restraint** | สีเขียวแบรนด์ `#0D7446` | ใช้เฉพาะ Primary Action, Active Tab, Focus Ring, และจุดเน้นหลัก ไม่ระบายใส่กล่องไอคอนทุกการ์ด |
| **Typography** | Sarabun, น้ำหนัก, Tracking | ใช้น้ำหนัก `400/500/600` เป็นหลัก (ไม่ใช้ `800–900` พร่ำเพรื่อ), ไม่มี `italic`, ไม่มีตัวพิมพ์ใหญ่ห่างๆ, ไม่มี negative tracking บนตัวเล็ก |
| **Icons & Copy** | Emoji, คำพูด, ป้ายตกแต่ง | **0 Emoji** ใน UI ทางการ, ไม่มีเครื่องหมาย `!`, ไม่มีคำโฆษณา, ใช้ไอคอนชุดเดียวขนาด `16–18px` ที่มีหน้าที่นำสายตาจริง |
| **Visual Hierarchy** | รูปแบบ KPI และกราฟ | ไม่เป็นกำแพงการ์ด 8 ใบหน้าตาซ้ำกันหมดแบบเทมเพลต AI (หากใช้ KPI Grid ต้องสมมาตรไร้แถวแหว่ง เช่น `3x2` หรือ `4x1`, ใช้ขอบบาง 1px และสีตัวเลขสื่อความหมาย), กราฟหลักไม่เกิน 1 ชิ้นใหญ่ ไม่มีแท่งสีรุ้ง |
| **Smart Subtraction** | ตัดส่วนเกินที่ทำให้ดูเป็น AI | • ไม่มี Eyebrow Pill Badge เหนือ `<h1>`<br>• ไม่มีเลขลำดับ `1. 2. 3.` หน้าชื่อเมนู/หัวข้อ/แท็บวันที่<br>• **ไม่มีวงเล็บหรือ Badge ช่วงวันที่ซ้ำซ้อน** เช่น `(1 ต.ค. ... — 30 ก.ย. ...)`<br>• ไม่มีดรอปดาวน์เลือกฟิลด์ค้นหา (ใช้ Unified Global Search)<br>• ไม่มี Tag ช่วงอายุแปะข้างข้อมูลปกติ<br>• ไม่มีปุ่ม Copy ในเซลล์ตาราง<br>• **ไม่มีแถวสรุป `<tfoot>` ท้ายตารางที่ซ้ำซ้อนกับ Pagination Bar** |
| **Motion** | CSS Transitions | ไม่มี `transition: all`, ไม่มี `hover:scale` บนการ์ด, ไม่มี `animate-pulse` บน element ที่ไม่ได้กำลังโหลด |

## 3. Spacing, Table Alignment & Lists Breathing Room

| หัวข้อ | เกณฑ์ผ่าน |
|---|---|
| **4px Grid & Breathing Room** | ทุก Margin/Padding/Gap ลงตัวบนสเกล `4px`, Card padding `20–24px`, Section gap `24–32px`, แถวตารางสูง `>= 52–56px` |
| **Lists & Sidebars Inset** | รายการแถวใน Sidebar/Menu มี Inset ห่างจากขอบอย่างน้อย `6–8px`, ระยะห่างไอคอนกับข้อความ `>= ครึ่งหนึ่งของไอคอน (8–10px)`, ระยะห่างระหว่างกลุ่มเมนูกว้างกว่าระยะห่างระหว่างแถว 2–3 เท่า |
| **Nested Radius Math** | มุมด้านใน `= max(4px, outerRadius - innerPadding)` (ปุ่ม/Input `8px`, การ์ด `12–16px`) |
| **Single-Row Date Ribbon** | `กำหนดเอง \| เดือน \| ปีงบประมาณ` และตัวเลือกวันที่อยู่บรรทัดเดียวกันบนเดสก์ท็อป คั่นด้วยเส้นตั้งบาง `1px`; **ไม่มี label ข้อความนำหน้า dropdown ปีงบประมาณ** (ค่าในตัวเลือกบอกอยู่แล้ว) |
| **Row-Clickable Table** | คลิกทั้ง `<tr>` เปิด Modal ได้โดยตรง มี hover feedback ชัดเจน ไม่เพิ่มคอลัมน์ปุ่มเปิดดู |
| **Table Header Row** | หัวตาราง **แถวเดียว** ไม่มีแถบหัวกลุ่มคอลัมน์ (`ข้อมูลผู้รับบริการ` / `เกณฑ์...`) · **ทุกหัวช่องกึ่งกลาง** · `sticky top: 0` + พื้น `--bg-subtle` + ขอบล่าง 2px |
| **`<th>` / `<td>` Harmony** | `td` จัดตามชนิดข้อมูล 100%: กึ่งกลาง (ลำดับ, วันที่, รหัส, ชื่อ-สกุล, Badge, จำนวน), ชิดซ้าย (ข้อความยาว), ชิดขวา (เงิน + ทศนิยมคงที่) |
| **Sort Icon Inline** | ข้อความหัวตารางและไอคอน Sort อยู่บรรทัดเดียวกันเสมอ (`inline-flex; white-space: nowrap`) |
| **Name & Age Wrap** | ชื่อ-สกุลยกไปทั้งนามสกุลเมื่อจอแคบ ไม่ตัดกลางพยางค์; อายุและคำว่า `ปี` อยู่บรรทัดเดียวกัน (`18 ปี`) |
| **Tabular Numbers** | ตัวเลข วันที่ เวลา และเงินทุกจุดใช้ `tabular-nums` และทศนิยมรูปแบบเดียวกัน |

## 4. Accessibility, States & Hospital Standards

| หัวข้อ | เกณฑ์ผ่าน |
|---|---|
| **Touch Target & Contrast** | ปุ่มและจุดกดสูง `>= 44–48px`, คอนทราสต์ตัวอักษร `>= 4.5:1` (AA), มี `:focus-visible` ชัดเจน |
| **4 Reassuring States** | มีครบทั้ง Empty, No Search Results, Loading Skeleton (ไม่กระตุก), และ Error State ภาษาไทยสุภาพ |
| **ปี พ.ศ. ไทย** | วันที่ทุกจุดแสดงเป็น พ.ศ. ไทย (`formatThaiDate`) ห้ามปน ค.ศ. |
| **PHI ตามบริบทสิทธิ์** | • หน้าสาธารณะ / ทั่วไป: Mask เลขบัตรและ HN เหลือ 4 หลักท้าย<br>• หน้าตรวจสอบภายใน RCM (`/service/dashboard-rcm/**`): แสดง CID 13 หลักและ HN/VN เต็ม (มี Role Auth + `logThrottledAudit`) |
| **Template Test** | *ถ้าสลับชื่อระบบเป็นองค์กรอื่น หน้านี้ยังดูเป็นโรงพยาบาลเถินไหม?* (ตรวจภาษา ข้อมูลตัวอย่าง และ Visual Anchor ให้ตรงบริบทโรงพยาบาลจริง) |

## 5. Modal / Dialog Redline (ตรวจทุกครั้งที่แตะ popup รายละเอียด)

โครงมาตรฐานและเหตุผลอยู่ใน [components.md §7–§8](components.md) — ตรวจตามนี้:

| หัวข้อ | เกณฑ์ผ่าน |
|---|---|
| **โครง flex 4 ชั้น** | header / tabs / footer มี `flex: 0 0 auto`, body มี `flex: 1 1 auto; min-height: 0` → **แถบแท็บต้องสูงคงที่ `48px`** แม้เนื้อหาจะยาว (วัด DOM จริง ไม่ใช่ดูด้วยตา) |
| **การเลื่อน** | เลื่อนได้เฉพาะ body; `overscroll-behavior: contain`; หน้าเว็บด้านหลังเลื่อนไม่ได้ (ล็อก `html` + `body`); `document.scrollHeight === viewport height` |
| **ขนาดหน้าต่าง** | `max-height: min(90vh, 900px)`; ไม่ล้นจอ; มือถือ `< 768px` เต็มจอ `100dvh` |
| **แถบท้าย** | Primary 1 ปุ่ม + Secondary 1 ปุ่ม, `44px`, ไม่ถูกดันตกขอบล่างเมื่อเนื้อหายาว |
| **Dialog ซ้อน** | `role="alertdialog"` + `aria-labelledby`/`aria-describedby`, `autoFocus` ที่ปุ่ม, `Escape` ปิดตัวซ้อนก่อน |
| **No Emoji / No inline style** | 0 Emoji ในหัวข้อ/แท็บ/ป้าย (ใช้ `lucide-react` 16–18px) และไม่มี `style={{ color/size }}` — เหลือได้เฉพาะ `width/minWidth` ของคอลัมน์ตาราง |
| **ตารางในหน้าต่าง** | มี wrapper `overflow-x: auto` + `min-width` ตาราง เพื่อไม่ให้คอลัมน์บีบ; เงินชิดขวา `tabular-nums` |
| **Grid ในการ์ด** | จำนวนช่องสมมาตร (3×3, 2×2) ไม่มีช่องแหว่งท้ายแถว |
