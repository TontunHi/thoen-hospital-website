```
# Design Spec: <ชื่อหน้า>

หน้า: `<path>` (<ใครใช้>)
ใช้ design tokens ชุดเดียวกับ <spec หน้าอื่นถ้ามี>

| # | ส่วน | เนื้อหา |
### 2.x รายละเอียดแต่ละส่วน (คอลัมน์, ขนาด, พฤติกรรม)

| หัวข้อ | กติกา |      (การจัดอันดับ, จัดกลุ่ม, ตัวกรอง, สถานะว่าง, สิทธิ์การมองเห็น)

## 4. สี (ถ้าใช้สีสื่อความหมาย)
| ความหมาย | พื้น | ตัวอักษร | ใช้ที่ |

| ความกว้าง | พฤติกรรม |
```
