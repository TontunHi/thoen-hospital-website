# โครงร่าง Design Spec ที่ต้องส่งมอบ (Spec Template)

ตั้งชื่อไฟล์: `<ชื่อหน้า>-design-spec.md` ใช้ภาษาไทยและเน้นตารางสรุปที่กระชับ

---

```markdown
# Design Spec: <ชื่อหน้า / ระบบ>

- **Path:** `<เส้นทางหน้า เช่น /member/events>`
- **กลุ่มผู้ใช้งาน:** <บุคลากรทั่วไป / พยาบาล / หัวหน้ากลุ่มงาน / แอดมินระบบ>
- **Design Tokens:** อิงตาม `src/app/globals.css` (สีหลัก --primary: #0D7446, Sarabun)

---

## 1. ปัญหาของหน้าเดิม และสิ่งที่แก้ไข
| # | ปัญหาเดิมที่พบ | สิ่งที่ได้รับการปรับปรุงในเวอร์ชันใหม่ |
|---|---|---|
| 1 | <เช่น ตารางล้นหน้าจอมือถือ> | <ห่อด้วย overflow-x: auto และปรับเป็น Card บนหน้าจอเล็ก> |
| 2 | <เช่น มีปุ่มสีสับสนหลายปุ่ม> | <รวมเป็นการกระทำหลัก 1 ปุ่ม (Primary) และลิงก์รอง> |

---

## 2. โครงสร้างหน้า (เรียงจากบนลงล่าง)
| ลำดับ | ส่วนประกอบ | รายละเอียดและพฤติกรรม |
|---|---|---|
| 1 | ลิงก์กลับ | `← กลับ...` |
| 2 | ส่วนหัว (Header) | ชื่อหน้า H1 + คำอธิบาย + ปุ่ม Action หลัก |
| 3 | แถบสรุป (Summary Bar) | ตัวเลขสรุปยอดสถานะรวมในแถบเดียว |
| 4 | แถบเครื่องมือ (Toolbar) | แท็บคัดกรองสถานะ + ช่องค้นหา Live Search |
| 5 | เนื้อหาหลัก (Content) | ตารางข้อมูล (Table) หรือการ์ดรายการ |

---

## 3. กติกาการแสดงผลและตรรกะทางธุรกิจ (Display & Logic Rules)
| หัวข้อ | กติกาที่กำหนด |
|---|---|
| **การเรียงลำดับ** | <เช่น เรียงตามวันที่ล่าสุดก่อน หรือเรียงตามความเร่งด่วน> |
| **การแสดงวันที่** | ใช้ **ปี พ.ศ. ไทย** เสมอ (เช่น "12 ต.ค. 2569") |
| **การปกป้องข้อมูล (PHI)** | Mask เลขบัตรประชาชนและ HN แสดงเฉพาะ 4 หลักท้าย |
| **สถานะว่าง (Empty)** | แสดงข้อความชี้แจงสาเหตุพร้อมปุ่มนำทางต่อ |
| **สิทธิ์การเข้าถึง (RBAC)** | <ปุ่มที่มองเห็นเฉพาะระดับ Manager หรือ Admin> |

---

## 4. โทนสีและสถานะที่ใช้งาน (Semantic Colors)
| สถานะ / ข้อมูล | CSS Variable | ค่าสีพื้น / ตัวอักษร | วัตถุประสงค์การใช้ |
|---|---|---|---|
| สีหลัก | `var(--primary)` | `#0D7446` / ขาว | ปุ่มหลักของหน้า, แท็บที่เลือก |
| รออนุมัติ | `var(--warning-*)` | `#FEF3C7` / `#B45309` | รายการที่ต้องรอเจ้าหน้าที่ตรวจสอบ |
| ยกเลิก / ปฏิเสธ | `var(--danger-*)` | `#FEE2E2` / `#B91C1C` | รายการที่ไม่ผ่านการอนุมัติ |

---

## 5. การตอบสนองบนอุปกรณ์ (Responsive Design)
| ขนาดหน้าจอ | พฤติกรรมการแสดงผล |
|---|---|
| **หน้าจอคอมพิวเตอร์ (≥ 1024px)** | แสดงตารางข้อมูลแบบเต็ม มีคอลัมน์ครบถ้วน |
| **แท็บเล็ต / จอขนาดกลาง (768px - 1023px)** | ซ่อนคอลัมน์ที่ไม่จำเป็น หรือใช้การเลื่อนในกล่องตาราง |
| **มือถือ (< 768px)** | ปรับแถบ Toolbar เป็นแนวตั้ง, ตารางเลื่อนแนวนอนอิสระ, ปุ่มกดสูง ≥ 44px |

---

## 6. ความเข้าถึงได้และความปลอดภัย (Accessibility & Security)
| หัวข้อ | การดำเนินการ |
|---|---|
| **Contrast Ratio** | ตัวอักษรทุกจุดมีอัตราส่วนคอนทราสต์ ≥ 4.5:1 |
| **Keyboard Navigation** | โฟกัสเห็นชัดเจนด้วย `var(--primary)` outline |
| **Audit Logging** | การกดปุ่มเปลี่ยนสถานะสำคัญ ต้องบันทึก Audit Log เสมอ |

---

## 7. ข้อมูลที่ต้องใช้จาก API Gateway
| ฟิลด์ข้อมูล | แหล่งที่มา / วิธีใช้ |
|---|---|
| `id` | รหัสอ้างอิงของรายการ |
| `status` | รหัสสถานะสำหรับกำหนดสีป้าย Badge |
| `thaiDate` | วันที่จัดรูปแบบ พ.ศ. มาจากระบบ |

---

## 8. สิ่งที่ตัดออกจากหน้าเดิม (Subtraction Pass)
| สิ่งที่ตัดออก | เหตุผลที่ตัด |
|---|---|
| <เช่น ไอคอนตกแต่งหน้าการ์ดทุกใบ> | <รกสายตา ไม่ได้ช่วยให้เข้าใจความหมายเร็วขึ้น> |
| <เช่น การ์ดสรุปแยก 4 ใบ> | <รวมเป็นแถบสถิติเดียวเพื่อประหยัดพื้นที่แนวตั้ง> |

---

## 9. หมายเหตุเกี่ยวกับต้นแบบ (Prototype Notes)
| เรื่อง | รายละเอียด |
|---|---|
| **ข้อมูลจำลอง (Placeholders)** | <ระบุข้อมูลที่ยังไม่ใช่ข้อมูลจริงจากฐานข้อมูล> |
| **ฟังก์ชันที่ยังไม่ได้เชื่อมต่อจริง** | <ระบุปุ่มหรือฟังก์ชันที่ยังเป็น Mockup หน้าบ้าน> |
```
