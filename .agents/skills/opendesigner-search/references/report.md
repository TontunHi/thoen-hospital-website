# The report

Lead with the finding that costs the most, even if nobody asked about it: a public page behind a sign-in outranks every title. Then:

1. **Can a stranger read it:** what was fetched logged out, and what came back.
2. **Rule checks:** `search.py`'s errors, then its warnings, grouped. Each with the file or URL and the value it saw. Notes (info) in one line each.
3. **The answer engines:** a table per question, with the engine, what it searched, what it read, whom it named and whether it was right. Say "not shown" where an engine hides its searches.
4. **Proposed fixes:** each with the evidence that led to it (`fixes.md`), most valuable first, and what it changes on which page.
5. **Off the site:** places to be listed, each waiting for the owner's yes.
6. **What needs the owner:** Search Console or Bing Webmaster reports, keyword data, decisions on training crawlers, approvals.

Say what turned out fine, too: "I expected X; here is why it isn't a problem". A suspicion that was checked and dropped is part of the evidence.

Plain words, with the term once in brackets the first time: "answer engines (AEO)".
