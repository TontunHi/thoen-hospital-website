# Illustration directory

Generated by `tools/build_data.py` from `synthesis/illustration-sources.json` (licences read on 2026-09-28). Licences change: open the licence link before you ship. **Agent fetches** means `illustrate.py search` queries and downloads it over HTTPS; **you download** means the site forbids automation, so the person picks and downloads and `illustrate.py add` brings the file in; **agent may browse** means bots are allowed but illustrate.py has no connector, so the agent browses or calls the site's API with its own tools. For the browsable page with filters and one search box for every site, run `python3 scripts/illustrate.py directory --open`. How to search well: `searching.md`.

## How to use each one

### Openverse (WordPress; Creative Commons search)

- **Good for:** onboarding, hero, feature, about
- **Search:** `https://openverse.org/search/image?q={q}&extension=svg&license_type=commercial,modification` · filters: licence (cc0, pdm, by, by-sa), licence type (commercial, modification), extension, category (illustration, photograph, digitized_artwork), source, aspect ratio, size
- **Formats:** SVG, PNG, JPG
- **Limits:** Openverse does not verify licences; check the item page before shipping
- **Tip:** Agents use the API (illustrate.py search); the website turns away scripts
- **Tip:** category accepts only illustration, photograph or digitized_artwork; results stop at 240
- **Tip:** All words must match: search one noun (hedgehog + svg gave 40 results, "hedgehog cartoon" gave 0)
- **Tip:** Every item's licence is its own: read it on the item's landing page
- **Tip:** Photos: illustrate.py photos search "<scene>" (category photograph; items naming an AI image tool are dropped)
- **Agent steps:** (1) illustrate.py search "<words>" --source openverse → (2) illustrate.py rank, then sheet --candidates → (3) Open the item's landing page and confirm the licence

### Wikimedia Commons

- **Good for:** error-404, feature
- **Search:** `https://commons.wikimedia.org/w/index.php?search={q}+filemime%3Aimage%2Fsvg%2Bxml&title=Special:MediaSearch&type=image` · filters: filemime:image/svg+xml, incategory:"...", licence shown per file
- **Formats:** SVG, PNG
- **Limits:** ShareAlike files pass their licence on to changed versions; results lean to diagrams and emblems
- **Tip:** filemime:image/svg+xml keeps SVGs only (the script adds it); OR works: rocket OR astronaut
- **Tip:** hastemplate:"Cc-zero" keeps CC0 files; deepcat:"SVG people icons" searches a whole category tree (20,848 files)
- **Tip:** insource:"openclipart" finds Openclipart's CC0 art mirrored on Commons (4,032 files)
- **Tip:** Copy the credit line from the file page (Use this file)
- **Tip:** Photos: illustrate.py photos search "<scene>" (JPEGs, downloaded at 1920 px)
- **Agent steps:** (1) illustrate.py search "<words>" --source commons → (2) Rank and look at the sheet → (3) Check the licence block on the file page
